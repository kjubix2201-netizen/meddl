# Changelog

All notable changes to meddl are documented here. meddl started as a fork of
[IPTVnator](https://github.com/4gray/iptvnator) (MIT License); its history up
to the fork lives in that project's releases.

# [0.25.0](https://github.com/kjubix2201-netizen/meddl/releases/tag/v0.25.0) (unreleased)

## Highlights

### meddl, a new home for the player

meddl is based on the IPTVnator 0.25 development line and keeps all of its
features: M3U/M3U8 playlists, Xtream Codes and Stalker portals, EPG/XMLTV,
catch-up, movies and series, favorites and the download manager.

- New name, icon and app identity. meddl keeps its library in its own data
  folder, so it can be installed next to IPTVnator without sharing data.
- Updates come from the meddl GitHub releases.
- Donation and community links of the original project were removed from
  the About page; it now credits the original project instead.
